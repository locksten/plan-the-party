# Nunito

This directory contains the normal-style variable-weight Latin and Latin Extended
subsets of Nunito from `@fontsource-variable/nunito` 5.2.7.

- Upstream font: <https://github.com/googlefonts/nunito>
- Packaging source: <https://fontsource.org/fonts/nunito>
- License: SIL Open Font License 1.1; see `OFL-1.1.txt`

Only these two subsets are shipped because they cover the application's Lithuanian
text without including unrelated Cyrillic or Vietnamese font files.
